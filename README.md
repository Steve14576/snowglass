# snowglass

把 Qwen3.5-9B 的真实权重画成三维「水晶内雕」结构的实验项目。当前阶段是自用观察／调试器，不是可直接交付的产品编辑器。

## 主文件是哪个

**当前唯一在用的主文件：**

```
prototype/editor_ux/20261122-055413-124110/index.html
```

访问入口 `http://127.0.0.1:8128/`。当前 8128 的服务目录已指向这个版本目录，所以打开就是编辑器；若改用项目根作为服务目录，项目根的 `index.html` 会跳到这里。

目录名是生成的批次时间戳，不是版本号。换主批次时需同步项目根 `index.html`、`scripts/serve_editor.py` 的 `BUNDLE` 和此处入口说明；当前没有新建编辑器版本。

启动命令（项目根执行）：

```powershell
uv run --offline --script scripts/serve_editor.py
```

计算服务同时监听 `127.0.0.1` 和 `::1` 的回环接口，兼容浏览器与 IDE 内嵌预览，不对局域网开放。以前的 `http.server --bind ::` 只能看静态页面，而且监听全网接口；有计算接口后不再使用它。请求需要同源与本机任务令牌，令牌不写入工程文件。

必须走 http，不能双击 `index.html` 用 `file://` 打开：浏览器会以 403 拦掉同目录的拓扑与统计文件，页面会显示提示横幅而不是数据。

世界坐标统一为右手Z-up：**+X从左到右，+Y从前到后，+Z从下到上**，负向相反。正面观察是眼睛在−Y侧向+Y看，俯视是从+Z向−Z看；视觉塔仍在主塔+X右侧。视口左下轴图随相机转动，表示世界轴，不是选中对象的局部轴；不进入加工作品。相机、gumball及数字变换也采用这套坐标，不只是改图例。

新工程记录`coordinateSystem: snowglass.xyz-z-up.v1`。旧工程没有坐标标记时，按`(x旧,y旧,z旧) → (x旧,−z旧,y旧)`转换对象变换、新版标注参考和相机，保持物理布局与观察投影；旧块标签文字与偏移已废弃，不再迁移；有标记就不重复转换。浏览器从旧`.v2`读取兼容状态，写入独立`.v3-zup`，不删除／覆盖旧键，磁盘旧工程也不覆盖。字体和原权重网格的局部数据不重排，矩阵负责映射到新世界坐标。刷新页面即可使用，不需要重新切片。

## 独立标签怎么生成

1. 选一个塔内源块，展开“文字与输出”。“排列轴”选X／Y／Z，“聚合方式”各有三种：在所选块所在的两个平面之一拍平一列，或把整塔的垂直截面各合成一个标签。不是给每个体素贴字。比如Z方向／整塔每个XY截面，会按实际层位生成一排层标签；X方向／整塔每个YZ截面，会生成各功能列的标签。
2. 面板先显示数量、放置侧与朝向，不创建对象。默认Z上下排列主塔在左、视觉塔在右、字面朝−Y（朝前）；X左右排列在塔后+Y侧、字面朝+Z（朝上）；Y前后排列在塔外侧、字面朝+Z。外侧按整张文字矩形留1mm可调初始间距，不是加工安全距离。头、尾、脖子和视觉端部等独立块只生成一个标签。
3. 点“生成独立标签对象”，确认后在“工程 → 标注”下建立标签组和具体标签。选组可整排移、转、缩；展开“变换 · 相对默认位置”，可选“旋转／缩放中心”：整组中心会一起改变排布，各标签自身中心保持每个标签位置，只改各自朝向／尺寸。两种模式平移一致，切换不重置排版；默认整组中心。选单个可改自己的文字、字体、实际毫米高度与变换。一次生成或拖动算一次撤销。组名和组样式不会改成员文字；同源同模式再次生成会提示定位旧组或明确追加，不覆盖原排版。
4. 整组跟随生成时选中的源块平移／旋转，不继承源缩放，也不跟随相机。组和单标签的手动调整继续叠加。删除源块会保留最后文字位置并解除跟随，删除标签组不删源块。模型打组不改变拓扑中的固定源塔身份，生成器不把操作组当模型结构。
5. 只使用新版独立标签，旧块标签控件、Sprite和旧`results[].label`导出已移除。源块文字属性只保留生成入口以及新标签默认字体／字号；临时查身份用鼠标悬停。生成后选标签组或标签，只需“启用标签（显示并输出）”：启用时显示且进入输出，停用时不显示、不进入切片内容。组的未覆盖成员跟随，已锁定成员保留自身值。镜头外、背面或被挡住不等于停用。
6. 旧工程的旧块标签文字、偏移与开关直接忽略，不转成新版标签，不因旧全局开关开启而自动生成370个标签；模型身份、几何、灰度与已有新版标注保留。旧版独立标注的显示状态转换成单一启用值，旧输出开关不再参与决策。字体／字号继续用于新标签生成默认和已创建对象的样式。
7. 工程保存包含全部标注对象、启用状态和绑定。“保存标注定义”可单独保存停用标签以便再编辑，不要求权重缓存；灰度映射的`annotations`只包含启用标签。当前仍是固定文字纹理平面，未生成厂家可加工字形轮廓。固定朝上的文字从正面看可能只见侧边，需要从+Z向−Z观察，字不会自动转向相机。
8. 新生成的同一组默认共用字号；同一字体的每条文字使用相同字体缩放比例，不因含下伸字母、中文或文字长短而逐条归一化。组里的“统一字号标尺 mm”默认0.7，是字体字号，不要求不同字符的实际墨迹高度相同。已有单标签字号覆盖和手动缩放保留。旧工程标签先保持原尺寸；实际修改组字号时，跟随该字号的成员转用统一标尺。
9. 选标签组，在“文字与输出”里用“组内文字对齐”选择左／右／居中。这是整组各条文字贴齐共同左边、右边或中线，只移动位置，不改变字号、字宽或字间距，没有“两端撑开”。左右按组的局部X方向判定；原位置先保留，选择后才执行对齐。改文字／字体／字号会保持该边线，gumball仍可单独微调。对齐方式、参考线和最终矩阵随工程保存。

字号与对齐专项用`--phase text-layout`，核验统一缩放比例、三种共同边线、字距／字号不受对齐影响、改字后保持边线、源跟随和保存。单标签系统专项用`--phase single-labels`，核验旧字段忽略、新版对象保留、单开关与导出一致、相机无关和工程往返。双中心专项用`--phase pivots`，覆盖各标签中心不动、所有轴／负值／非均匀缩放、平移一致、嵌套源跟随、数字输入、多帧gumball及保存恢复。标注专项：把上述测试命令的`--phase full`换为`--phase annotations`。合成九模式、真实拓扑、跟随／分组／失源／旧工程，以及实际生成控件、中文测量、gumball、选择和保存均有断言；不截图、不计算权重。

## 主预览的分批显示与交互概览

主页面`http://localhost:8128/`已经接入高清文字与分批雪花显示。准备仍不画雪花，标签、结构和编辑保留；点预览后先进入可操作视口，逐块读取现成统计，逐批建立真实雪花，不再等全量实例建立完成才切换。预览左上显示“正在分批细化／交互概览／细节已完成”，并有“暂停细化／继续细化”按钮；暂停保持真实格子概览，不新增第三视图。

转动、右键平移、滚轮缩放及gumball交互期间，显示从已载入格子按固定索引确定性取样的点状概览。它不是随机模拟纹理，也不写回mask、统计或灰度映射。松手后恢复已经有效的细节，未完成的继续分批建立；再次拖动会暂停待建实例。模型变换时概览即时跟随包络，完整立方体仍按原规则保持毫米边长。读文件、JSON解析与数值数组传输使用工作线程，灰度映射每8192值让出执行，建实例每批最多4096格、每次调度目标6ms并最多4块；这些是显示实现初值，不是加工或科学参数。

取景以**世界坐标原点**为主动作基准：点全景／正面时原点落在画面正中，转动和滚轮缩放都绕它；全景／正面只按作品包围盒算出相机距离，保证整件作品入镜，不把焦点挪到包围盒中心或毛坯。左键旋转、右键平移、滚轮缩放；**右键平移会同时带走焦点**，这是平移视角的正常行为——平移之后旋转和缩放围绕屏幕中心那个新点，想回到原点就再点一次全景。右键按下时会临时关掉移动手柄，避免落在手柄上时把对象拖走；只有左键参与选择与框选；打开旧工程时保留当时的观察方向与距离，但焦点同样归到原点，旧工程存的旧中心不会再把模型推出画面。因此模型相对原点偏右（模型几何中心约 x=8.94mm）是真实几何关系，不是画面错位。全景按 `work` 块包围盒定距离，毛坯在 `refs` 节点下、不计入作品范围。

最终画布／文字像素比上限2，雪花／结构离屏上限1.25，沿用独立页验证的单GL色深合成；文字、手柄和高亮在高清层绘制。深度边缘与透明混合仍有近似，不把分层说成免费加速。固定尺寸重用离屏缓冲，拖动不会改像素比或重新分配整张画布。WebGL1回退整画布绘制。

显示实例配置上限400万、当前统计工作集上限800万候选格、概览最多12.8万点；达到上限明确显示状态，其余结果仍在磁盘，不假装全部细节已显示。超大工作集可先回准备选焦点，再进预览优先读取；这一版没有自动远近LOD或所有设备通用的预算调参。实际文件、显存和绘制成本仍存在，渐进解决的是长任务对操作的占用，不承诺总耗时下降。准备统计反馈暂取所选范围前8项；导出仍按真实作用范围读完整数据，不受显示预算限制。

主页面专项：`uv run --offline --script tests/test_progressive_preview.py`，现为10项通过，报告`prototype/editor_ux/20261122-055413-124110/verification/progressive-20261127-093912-214487/checks.json`（前一轮9项报告`progressive-20261127-075738-387716`保留）。新增用例核对取景基准：焦点恰为`[0,0,0]`、平移关闭、原点投影恰在画面中心、滚轮放大后焦点与原点中心不变。报告实测`fit`后原点NDC约`3e-18`、放大后约`1e-16`；完整原功能回归61项通过，报告同目录`run-20261127-075844-069498/checks.json`。核验现成369块／3,620,608格与32个测试标签、实际拖动、暂停／继续和返回准备；新增全部GPU颜色缓冲容量检查，以及静止画面与旧正常绘制路径的雪花开关像素差分。测试没有新切片请求，原科学脚本与旧缓存哈希一致，已有工程文字、布局、双中心和切片引用保留。视觉由用户手动查看，不自动截图。

## 独立画质对照页

入口为同一8128服务的`/render_lab/`，文件是`prototype/editor_ux/20261122-055413-124110/render_lab/index.html`；主编辑器仍在`/`，不用新开计算服务。与主页面保持相同的localhost或127.0.0.1地址，以便只读取得该地址下的自动保存工程；也可点“载入主工程文件”。文字内容、字体、字号、启用状态、排版、来源跟随与相机都从主工程读取，不自动生成标签，不写回自动保存。

默认项目为“整场高清／雪花适度＋文字高清”：A在最终画布分辨率直接画整个场景；B先在较低分辨率画雪花和结构，再合成颜色／深度并高清画原三维文字。默认最终画布像素比上限2（A/B共用），B雪花／结构上限1.25；文字贴图和过滤同样共用，字号、字距、朝向、对齐、灰度及实例数量不变。按1／2切换，不改相机；这些控件供实验诊断；主编辑器不暴露像素比数字，现用相同的2／1.25分层起始配置。低DPI下两档采样密度可能相同，页面会提示，可显式选固定2。

实现为单个GL上下文的三次绘制：低分辨率RGBA8＋深度缓冲 → 颜色线性放大与深度最近邻传递 → 高清三维标签。离屏目标采用与默认画布相同的实际抗锯齿采样数，固定尺寸时重用，不每帧分配。保留不透明雪花等几何对文字的前后遮挡；低分辨率深度边缘为近似，透明框壳先合成、文字后画的混合顺序也可能不同，必须对照观感。WebGL1明确回退整场景，不伪装分层。页面显示两种画布尺寸、绘制次数与离屏缓冲占用估算；离屏合成有成本，不保证更快。

原“只比分辨率／只比文字过滤”项目仍保留：这些项目的A代表旧主文件画质（上限1.25、无mipmap线性过滤），B改所选参数。独立页仍保持固定实例对照，不执行主预览新增的交互轻化与渐进加载；它不写回切片产物或工程。

只GET读取现成切片清单和成功张量，再用主文件的数据映射与绘制模块展示。雪花来源按以下顺序：工程引用的任务 → 工程没有引用时，只读选取已完成且张量最多的任务（当前为`slice-20261123-015539-615436`，369块／761张量／3,620,608候选格）→ 都没有才用主文件内的65块代表缓存。任务清单来自本机服务的只读`/api/slice1/jobs`，不启动、不续跑、不改结果。

文字标签只存在工程里，不在缓存中。读不到主工程时，页面顶部会明确写出“当前地址没有读到主工程，因此没有你的文字标签”，不会静默退回代表缓存。自动保存按浏览器和网站地址隔离：主页面用`localhost:8128`，对照页也要用`localhost:8128/render_lab/`；不一致时点“切换地址读取”。也可从主页面保存工程文件后在这里载入。“展示范围”可选全部已有缓存、主工程所选来源，或只看结构不载入雪花（便于先核结构）。

短测按钮比较同场景各5次绘制＋GPU完成等待，分层档包含全部三次绘制与合成，不包括统计读取／实例构建，不是完整编辑器FPS；全量雪花短测前会确认。

## 一级切片怎么用

1. 选择对象或组，在参数栏的“一级切片 · 统计生成”中调整三轴网格上限，数字框和滑块共用参数；未覆盖项继承上级。默认数据局部网格 `16×16×32` 沿用原实验，不是世界XYZ；坐标迁移不换格数或缓存签名。实际格数可能更少，每格合并多少以 `counts` 为准，不把固定网格冒充已拍板的固定压缩倍数 n。
2. “输出灰度 · 即时缓存映射”中的“统计来源”同时决定需要生成哪些统计：`full`只直接池化，`rowcol`才算行列强度，`feature/residual`才运行原SVD并成对生成。已有匹配通道即时映射；未生成的通道提示点击切片，不用full冒充，也不自动启动计算。
3. “一级切片 · 统计生成”中另有“权重数值约定”（GGUF原值／HF约定对齐）和“额外诊断统计”。新工程默认GGUF原值、诊断关闭；旧工程缺新增字段时保留HF旧约定，新增诊断开关默认关闭。HF对齐不是找回量化前精度。读取／解量化、全覆盖池化、计数与必要校验始终保留。
4. 右上切片范围选“作品范围”或“所选对象”，确认清单、谱／行列／诊断块数后才执行。各块继承后的来源、约定、网格及诊断选项形成固定快照，不能只看全局值而忽略局部覆盖。
5. 显示逐张量进度、心跳、复用与失败数量；可取消。失败或取消不删除已完成结果。再次建立同一配置任务会核对签名、当前原张量字节 SHA256 和结果 SHA256，只补缺项。
6. 完成后自动进入预览，画全部已载入统计。网格、约定、缺失来源或所需诊断改变时显示“待切片”；旧结果若继续显示会明确标示。不同约定／网格缓存分开保存，同一配置补一个通道不丢掉其他通道。灰度、窗口、已算通道、曲线、包络、排布和小块毫米边长不使源统计过期。包络变化会重新摆放中心点，小块自身仍保持毫米边长。
7. 工程保存切片任务编号，重新打开可恢复引用。新产物在 `out/slices/jobs/<任务编号>/` 和 `out/slices/artifacts/<签名>/<尝试编号>/`；已完成任务拒绝覆盖。

离线入口仍可用：`uv run --offline --script scripts/slice1.py --request <请求JSON路径>`，请求为 `{"blocks":[{"id":"L00.attn_norm","grid":[16,16,32],"source":"full","convention":"gguf","diagnostics":false}]}`。省略后三项也采用这组轻量默认值，选项进入计算签名；feature与residual共享成对谱结果的签名。每次新建任务，通过完成张量复用实现续跑，不覆写原实验目录。

合成核验：`uv run --offline --script tests/test_slice1.py`。界面／真实小样核验用 `tests/test_slice1_flow.py --real --url http://127.0.0.1:8128/`，只触及 `L00.attn_norm` 一个4096元素张量，报告在 `out/slices/verification/`。

## 现状边界

已接入：本机一级切片任务、按需统计、可选HF约定对齐／额外诊断、作品／所选范围、局部继承网格、进度／取消／完成项复用、结果引用恢复与准备／预览两态、九种独立标注生成与固定朝向，以及原有几何和灰度编辑。完整拓扑的任务清单是369块／761张量；一级切片接入只核验过一个真实小张量及合成数据，本轮标注只读现成缓存，**没有重跑原权重或完整模型**。既有任务与完成项保留，不覆盖或自动续跑。原有65组／124张量代表缓存继续保留。

未接入：二级加工导出、任意解析式、自适应、可调谱求解配方、加工字形轮廓、厂家读取契约。完整模型的运行时间、全部量化变体与全量渲染性能还未验证；不把接口可提交全范围宣称为全模型数据已经补齐。
