# snowglass

把 Qwen3.5-9B 的真实权重画成三维「水晶内雕」结构的实验项目。当前阶段是自用观察／调试器，不是可直接交付的产品编辑器。

## 主文件是哪个

**当前唯一在用的主文件：**

```
prototype/editor_ux/20261122-055413-124110/index.html
```

访问入口 `http://127.0.0.1:8128/`。当前 8128 的服务目录已指向这个版本目录，所以打开就是编辑器；若改用项目根作为服务目录，项目根的 `index.html` 会跳到这里。

目录名是生成的批次时间戳，不是版本号。换主批次时需同步项目根 `index.html`、`scripts/serve_editor.py` 的 `BUNDLE` 和此处入口说明；当前没有新建编辑器版本。

启动命令（项目根执行）：

```powershell
uv run --offline --script scripts/serve_editor.py
```

计算服务同时监听 `127.0.0.1` 和 `::1` 的回环接口，兼容浏览器与 IDE 内嵌预览，不对局域网开放。以前的 `http.server --bind ::` 只能看静态页面，而且监听全网接口；有计算接口后不再使用它。请求需要同源与本机任务令牌，令牌不写入工程文件。

必须走 http，不能双击 `index.html` 用 `file://` 打开：浏览器会以 403 拦掉同目录的拓扑与统计文件，页面会显示提示横幅而不是数据。

世界坐标统一为右手Z-up：**+X从左到右，+Y从前到后，+Z从下到上**，负向相反。正面观察是眼睛在−Y侧向+Y看，俯视是从+Z向−Z看；视觉塔仍在主塔+X右侧。视口左下轴图随相机转动，表示世界轴，不是选中对象的局部轴；不进入加工作品。相机、gumball及数字变换也采用这套坐标，不只是改图例。

新工程记录`coordinateSystem: snowglass.xyz-z-up.v1`。旧工程没有坐标标记时，按`(x旧,y旧,z旧) → (x旧,−z旧,y旧)`转换对象变换、标注参考、偏移和相机，保持物理布局与观察投影；有标记就不重复转换。浏览器从旧`.v2`读取兼容状态，写入独立`.v3-zup`，不删除／覆盖旧键，磁盘旧工程也不覆盖。字体和原权重网格的局部数据不重排，矩阵负责映射到新世界坐标。刷新页面即可使用，不需要重新切片。

## 独立标签怎么生成

1. 选一个塔内源块，展开“文字与输出”。“排列轴”选X／Y／Z，“聚合方式”各有三种：在所选块所在的两个平面之一拍平一列，或把整塔的垂直截面各合成一个标签。不是给每个体素贴字。比如Z方向／整塔每个XY截面，会按实际层位生成一排层标签；X方向／整塔每个YZ截面，会生成各功能列的标签。
2. 面板先显示数量、放置侧与朝向，不创建对象。默认Z上下排列主塔在左、视觉塔在右、字面朝−Y（朝前）；X左右排列在塔后+Y侧、字面朝+Z（朝上）；Y前后排列在塔外侧、字面朝+Z。外侧按整张文字矩形留1mm可调初始间距，不是加工安全距离。头、尾、脖子和视觉端部等独立块只生成一个标签。
3. 点“生成独立标签对象”，确认后在“工程 → 标注”下建立标签组和具体标签。选组可整排移、转、缩；展开“变换 · 相对默认位置”，可选“旋转／缩放中心”：整组中心会一起改变排布，各标签自身中心保持每个标签位置，只改各自朝向／尺寸。两种模式平移一致，切换不重置排版；默认整组中心。选单个可改自己的文字、字体、实际毫米高度与变换。一次生成或拖动算一次撤销。组名和组样式不会改成员文字；同源同模式再次生成会提示定位旧组或明确追加，不覆盖原排版。
4. 整组跟随生成时选中的源块平移／旋转，不继承源缩放，也不跟随相机。组和单标签的手动调整继续叠加。删除源块会保留最后文字位置并解除跟随，删除标签组不删源块。模型打组不改变拓扑中的固定源塔身份，生成器不把操作组当模型结构。
5. 初始不自动铺满标签。显式标注代表的成员会让原自动块标签暂时让位，旧`labels`／`labelText`覆盖仍保留；删掉显式标注后可恢复旧显示。其他未标注块不受影响。固定朝上的文字从正面看可能只见侧边，需要从+Z向−Z观察；字不会自动转向相机。
6. 工程保存包含标注对象和绑定。“保存标注定义”可单独保存文字、成员、实际世界矩阵与朝向，不要求已切权重；灰度映射另带`annotations`清单。当前仍是文字纹理平面，未生成厂家可加工字形轮廓。

双中心专项用`--phase pivots`，覆盖各标签中心不动、所有轴／负值／非均匀缩放、平移一致、嵌套源跟随、数字输入、多帧gumball及保存恢复。标注专项：把上述测试命令的`--phase full`换为`--phase annotations`。合成九模式、真实拓扑、跟随／分组／失源／旧工程，以及实际生成控件、中文测量、gumball、选择和保存均有断言；不截图、不计算权重。

## 一级切片怎么用

1. 选择对象或组，在参数栏的“一级切片 · 统计生成”中调整三轴网格上限，数字框和滑块共用参数；未覆盖项继承上级。默认数据局部网格 `16×16×32` 沿用原实验，不是世界XYZ；坐标迁移不换格数或缓存签名。实际格数可能更少，每格合并多少以 `counts` 为准，不把固定网格冒充已拍板的固定压缩倍数 n。
2. “输出灰度 · 即时缓存映射”中的“统计来源”同时决定需要生成哪些统计：`full`只直接池化，`rowcol`才算行列强度，`feature/residual`才运行原SVD并成对生成。已有匹配通道即时映射；未生成的通道提示点击切片，不用full冒充，也不自动启动计算。
3. “一级切片 · 统计生成”中另有“权重数值约定”（GGUF原值／HF约定对齐）和“额外诊断统计”。新工程默认GGUF原值、诊断关闭；旧工程缺新增字段时保留HF旧约定，新增诊断开关默认关闭。HF对齐不是找回量化前精度。读取／解量化、全覆盖池化、计数与必要校验始终保留。
4. 右上切片范围选“作品范围”或“所选对象”，确认清单、谱／行列／诊断块数后才执行。各块继承后的来源、约定、网格及诊断选项形成固定快照，不能只看全局值而忽略局部覆盖。
5. 显示逐张量进度、心跳、复用与失败数量；可取消。失败或取消不删除已完成结果。再次建立同一配置任务会核对签名、当前原张量字节 SHA256 和结果 SHA256，只补缺项。
6. 完成后自动进入预览，画全部已载入统计。网格、约定、缺失来源或所需诊断改变时显示“待切片”；旧结果若继续显示会明确标示。不同约定／网格缓存分开保存，同一配置补一个通道不丢掉其他通道。灰度、窗口、已算通道、曲线、包络、排布和小块毫米边长不使源统计过期。包络变化会重新摆放中心点，小块自身仍保持毫米边长。
7. 工程保存切片任务编号，重新打开可恢复引用。新产物在 `out/slices/jobs/<任务编号>/` 和 `out/slices/artifacts/<签名>/<尝试编号>/`；已完成任务拒绝覆盖。

离线入口仍可用：`uv run --offline --script scripts/slice1.py --request <请求JSON路径>`，请求为 `{"blocks":[{"id":"L00.attn_norm","grid":[16,16,32],"source":"full","convention":"gguf","diagnostics":false}]}`。省略后三项也采用这组轻量默认值，选项进入计算签名；feature与residual共享成对谱结果的签名。每次新建任务，通过完成张量复用实现续跑，不覆写原实验目录。

合成核验：`uv run --offline --script tests/test_slice1.py`。界面／真实小样核验用 `tests/test_slice1_flow.py --real --url http://127.0.0.1:8128/`，只触及 `L00.attn_norm` 一个4096元素张量，报告在 `out/slices/verification/`。

## 现状边界

已接入：本机一级切片任务、按需统计、可选HF约定对齐／额外诊断、作品／所选范围、局部继承网格、进度／取消／完成项复用、结果引用恢复与准备／预览两态、九种独立标注生成与固定朝向，以及原有几何和灰度编辑。完整拓扑的任务清单是369块／761张量；一级切片接入只核验过一个真实小张量及合成数据，本轮标注只读现成缓存，**没有重跑原权重或完整模型**。既有任务与完成项保留，不覆盖或自动续跑。原有65组／124张量代表缓存继续保留。

未接入：二级加工导出、任意解析式、自适应、可调谱求解配方、加工字形轮廓、厂家读取契约。完整模型的运行时间、全部量化变体与全量渲染性能还未验证；不把接口可提交全范围宣称为全模型数据已经补齐。
