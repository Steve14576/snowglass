# 全类型与前中后代表层探路

## 本轮目标与边界

用户确认“全类型＋前中后代表层，探路”。这不是全模型 761 个张量逐项切片，也不是宣布全注意力画法定稿。目标是把不同类型的真实参数都试到，看到完整功能组内各个张量怎样组合，保留不理想或不适用的结果。既有小样、主编辑器和源权重不覆盖。

已有连续灰度与空间筛选的实验见 `weight_sample_comparison.md`；本轮不再重复其全部推导。关键边界仍是：等大小小块携带连续灰度，厂家爆点另属工艺层；区域门槛不是重要性判断，不随机删点，不把谱残差当训练前噪声。UX 需求仍保存在 `editor_spec.md` 第15节，本轮只做类型观察页，不提前实现或拍板对象树、局部覆盖、字体等。

## 覆盖清单

层号均从 0 开始。按照功能类型在各自深度序列中的前／中／后选取：

| 部分 | 代表层／对象 | 本轮包含 |
|---|---|---|
| 全注意力文本层 | 3、15、31 | 每层全部 8 个功能块：输入 norm、Q/Gate 与 q_norm、K/V 与 k_norm、输出投影、后 norm、MLP gate/up/down |
| Gated DeltaNet 文本层 | 0、16、30 | 每层全部 8 个功能块；门控、Conv、alpha/beta、A_log、dt 与内部 norm 不遗漏 |
| 视觉重复层 | 0、13、26 | 每层 norm1、attention、norm2、MLP，含权重与全部 bias |
| 文本首尾 | Embedding、Final Norm、LM Head | 两张大矩阵分别全覆盖，不把抽取部分 token 冒充整张 |
| 视觉首尾 | Patch/Position、Merger/Projector | 功能组内全部张量 |
| MTP | 空框 | 文件没有该权重，明确缺失，不填假雪花 |

清单核验结果为 65 个含权重功能块、124 个独立张量，另有 MTP 空框；现有源清单的张量类型签名与量化格式变体均在这些代表样本中覆盖。未选层仍未跑，不宣称代表层穷尽层间差异。

## 类型处理

所有张量独立解码与统计，不混成一张矩阵。按拓扑记录执行 HF 数值约定还原；GDN 头置换使用此前在第0层核实的规则，其他代表层记录“沿用转换约定，未重新与远程 HF 核对”，不能当作新增的外部验证。

- 二维且两边至少 64 的矩阵：原始带符号矩阵上的谱重构、完整绝对值均值、残差幅度和行列 RMS 外积分别保存。RMS 外积是通道强度图，不代表低秩重构，也不自动与谱相加。
- 一维 norm／bias／控制向量，以及短卷积、很窄的控制矩阵和高维 patch 核：保留原形状与符号统计，使用幅度池化，不把它们硬套成谱矩阵。页面明确标“谱不适用，特征通道为直接幅度”。常数、零数组和还原后的零值也原样记录，不人为加纹理。
- 一个外层功能块中有多个张量时：分别计算，再在前端并排分区；保留张量名、尺寸、来源和图例。分区只是探路展示，不是按参数量或重要性分配加工体积。

### 谱算法与限制

默认探路设置：中小矩阵最多 256 个方向、额外 16 个过采样方向，比较第8与第12次正交幂迭代；阈值继续用 $\operatorname{RMS}(W)(\sqrt m+\sqrt n)$ 作历史方法参照。不能把它当普遍噪声边界。缓存报告保留数、方向上限是否碰顶、迭代变化；若达到上限，只是截断特征。

Embedding／LM Head 不同时展开原矩阵、重构和残差。采用 2048 行一批解码、96 个方向及额外16过采样方向、4次右侧子空间迭代的分块矩阵算子；全行全列参与，但这一档是低精度探路，未单独加深迭代核验。清单和页面标明与普通矩阵的256方向／12次不同，不将达到上限的结果称为完整谱特征。

### 折叠与合并

能从拓扑取得按头或 q/k/v 段规则的保留该结构；其余矩阵采用显式记录的长轴因子分解，向量按顺序分箱并折成近方形网格。每个源元素恰好参与一个合并格，不插值、不复制填满小张量。每区最多 16×16×32 格，小张量不足时使用更小网格；实际格数、每格元素数范围及折叠规则写入数据。

粗细尺度或其他合并规则会改变可见结构，本轮不把不同折叠下的形态说成天然三维组织。

### 统一对照

三列：完整幅度、选定特征不筛选、同一特征按门槛筛选且保留灰度。可切换谱／直接幅度／行列强度，谱不适用处明确提示并使用直接幅度。门槛在显影前作用，曝光、幂次不改变入选位置；不保留固定百分比，不用最大连通块过滤。

每张量参考白值为还原后 $2\operatorname{mean}|W|$，各版本共用，不跨张量宣称绝对亮度可比。均值为零时灰度全零，并明确标记，而不是除以一个任意很小的数制造亮度。

## 验证与运行纪律

先列清单与测试折叠／还原；再做普通张量和大张量的秒级探针。正式逐张量串行处理，BLAS限制4线程，父进程每10秒保留心跳；工作进程隔离本次计算，普通张量180秒、大矩阵420秒超时即停止当前工作进程并记录失败，后续重新启动继续。私有内存3 GiB停止线是当场选取的工程保护，不是加工参数；映射文件页引起的 RSS 增加与私有内存分开记录。每张量写独立数据、完成标记与SHA256，所以中断不等于前面结果丢失；不静默覆盖重跑。每次批次写新的 `prototype/data/type_surveys/<时间戳>/`，结果写后不覆盖，进度日志可追加。

验收包括：清单覆盖、源形状和格式一致、还原操作的单元测试、池化计数与加权均值守恒、有限非负幅度、三通道来源、合成块张量数、页面真实几何像素、空值／常数／不适用谱的提示，以及主编辑器不改动。

配套文件：`scripts/survey_data.py` 解码／还原／折叠，`scripts/survey_math.py` 各类型数学处理，`scripts/run_type_survey.py` 清单、探针、运行与核验，`scripts/summarize_type_survey.py` 只读统计汇总，`tests/test_type_survey.py` 合成数值检查，`tests/capture_type_survey.py` 全功能组浏览与截图。观察页为 `prototype/type_survey.html?run=<目录名>`，没有自动找最新目录，避免版本混淆。

### 哪些方法实际执行了

54张常规二维矩阵做了原始带符号矩阵上的谱计算与8／12次迭代对照；68张一维、窄矩阵、高维核等使用直接幅度，不假称做了谱提纯；2张首尾大矩阵使用96方向／4次流式计算。行列强度保留为独立可切换通道，不偷偷和谱结果加成“重要性”。

以下5项谱方向达到本轮上限：

| 张量 | 上限 | 影响 |
|---|---|---|
| `blk.15.attn_q.weight` | 256方向 | 第15层Q／Gate只是截断谱特征 |
| `token_embd.weight`、`output.weight` | 各96方向 | 首尾大矩阵虽然完整遍历，但谱特征未取尽，也未额外核对迭代精度 |
| `mm.0.weight`、`mm.2.weight` | 各256方向 | 视觉Merger／Projector的两张主矩阵只是截断特征 |

常规矩阵最大的8→12次谱池化相对L2变化约2.88%（`blk.30.ffn_down.weight`），其后是第3层up约2.71%、第0层up约2.62%和第31层down约2.45%。这是实际敏感性，不把12次统一称为已收敛。没有给这些张量自动加方向或隐式重跑；需要更高精度时必须作为下一轮显式实验。

### 同一门槛不适合全部类型

下面采用各张量原始幅度均值两倍作为参考白值、门槛0.25、默认特征通道（矩阵用谱，不适用处直接幅度）。这些是观察条件，不是加工条件或重要性判据。功能组统计含各自独立张量／段，没有把不同原始值先混成一张表。

| 功能组 | 入选格 / 候选格 | 观察 |
|---|---|---|
| 第3层Q／Gate，含q_norm | 2339 / 8448 | 主投影中有带状差异，小norm独立存在；不能将norm解释成谱块 |
| 第3层K／V，含k_norm | 1402 / 4352 | K、V的筛选条带位置与幅度不同，可分区看见 |
| 第3层输出投影 | 50 / 8192 | 同门槛下几乎全部被筛掉，不表示模型没有用到它 |
| 第0层GDN输入投影q/k/v | 13627 / 24576 | 三段分别保留，在切面上可以看到不同条带，不能据此声称天然三维团块 |
| 第0层GDN控制组，7张量 | 16373 / 25792 | 主门控投影在此门槛下全空，alpha/beta等直接幅度大量保留；混合方法与局部标尺必须明说 |
| 第0层GDN输出投影 | 1956 / 8192 | 可选出部分空间区域，但具体位置受折叠影响 |
| 第16层MLP gate / up / down | 82 / 0 / 0，各8192格 | 一个全局门槛会让部分功能组消失，需要手调或另选特征，不能预先强制保留比例 |
| Embedding／LM Head | 各0 / 8192 | 默认谱门槛下全空；0.15下分别有2685／8107格；当前谱截断不足以判定它们不存在可读特征 |
| 视觉Patch/Position | 23709 / 25344 | patch核直接幅度占主要部分，位置编码独立谱统计；不宜叫“去残差后纯信息” |
| 视觉Merger／Projector | 20629 / 21504 | 同门槛下仍很密，且两张主矩阵谱截断；不能用默认图评为最终画法已成功 |

页面切换通道时，如某小向量没有行列强度，明确提示并用直接幅度；汇总JSON的某通道只统计适用数据，不适用项为null，所以该通道的原始计数不能不加解释地与页面fallback总数相等同。

### 图像判断与局限

实际截图已经查看了K／V、GDN输入与控制组、MLP down、视觉MLP、Embedding和视觉投影器等代表图。浏览器绘制的每个实例来自确定的格值，验证不只检查canvas存在，还确认几何实际贡献像素。

这轮功能组分区按张量顺序，从左到右、从上到下观察；每个区域的候选格数不同。区域之间的间隙只是区分来源，不冒充原模型的接线或最终包络布局。默认曝光2会让完整幅度或小向量的一些值饱和，切面上的白色不能直接读成数值相同；页面报告饱和率，可手动降低曝光。规则阵列投影仍会出现排列线，不把全部三维条纹解读为权重特征。

GDN控制组和视觉复合组表明：一个盒子里的不同张量未必适用同样算法、同样分辨率或同样标尺。即使主矩阵筛成稀疏，小向量仍可密集；这是参数性质与显示规则的差异，不是处理失败时随便补出的雪花。

结论：全类型探路覆盖已完成，主编辑器的真实填充和最终画法没有因此定稿。现在可以按具体功能组讨论要保留完整幅度、谱特征还是行列强度，哪些分区需要手调，并复议压缩量与局部灰度。不能直接采纳“所有块纯谱＋统一0.25门槛”，也不需要每一块都变成漂亮片状来证明模型真实。

### 下一轮明确要回到的 UX

先看各类型实际分布，再从 `editor_spec.md` 第15节继续：分组对象的局部覆盖；机台全局与数据算法分开；筛选位置和显影灰度分开；gumball与数值共用状态；每个成员保留自己的标签；手动优先，不先做自适应。小样页面的分区工具、方向上限和门槛不是正式UI方案，不能因本轮已经编码就默认为用户接受。

原编辑器、原两块小样、旧科学产物、权重文件均未改写。下一轮任何覆盖性重跑或科学方法变更仍需确认；不在“探路完成”后自动继续改主编辑器。
