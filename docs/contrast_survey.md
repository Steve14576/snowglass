# 全类型灰度展开：独立副本

## 为什么做这轮

用户明确要求“上面的全都拉大再跑一遍，新开、不覆盖已有，数据文件可以复制成独立副本修改”。本轮覆盖已完成全类型探路的65功能组、124张量，保持前中后代表层范围，不重新解码权重或计算SVD。原始统计、原页面和当前副本分开，原件SHA256前后核对。

此前默认是每张量原始幅度均值两倍作为白值，整个0–1作显示标尺，又默认曝光乘2。某些池化图实际仅占很窄的区间，而曝光只会让它们更白，并没有扩大差异；饱和还会让不同数值看起来相同。当前需求允许观看真实数值纹理，不必把纹理都解释为集中知识结构，因此必须先展开已有差异再评价。

这里纠正的是观看验证，不声称池化丢掉的细节可以恢复，不把拉伸后的随机波动称作训练获得的知识。SVD与直接幅度保持不同语义，灰度窗口不决定功能重要性。UX需求仍在 docs/editor_spec.md 第15节，本轮是独立对照，非正式编辑器改版。

## 数据与文件隔离

源：`prototype/data/type_surveys/run-20261122-002935-897005/`。脚本 `scripts/prepare_contrast_survey.py` 创建 `prototype/contrast_survey/<时间戳>/`：

- `source_data/`：源manifest及124张量JSON的逐字快照。
- `original_files/`：旧观察HTML/JS/CSS和三维依赖快照。
- `data/`：保留原全部数值并增加各通道window与expanded数组的独立结果。
- `assets/`：基础CSS、相机与场景代码的副本，仅在副本上修改。
- `copy_verification.json` 与 `contrast_summary.json`：复制一致性、原件哈希、展开区间、恒定项和旧显示饱和率。

不依赖原页面的可变JS/CSS，不覆盖已有run目录。CDN仍沿用three.js r128。副本内任何映射试验只读其本地统计，不写原编辑器localStorage。

## 灰度规则

所有适用的full、feature、rowcol、residual通道分别处理。同一张量同一通道的所有子区共用最小值L与最大值H，不把q/k/v等子区各自强制拉满，保留彼此的相对差异。

$$g(v)=\operatorname{clip}\left(\frac{v-L}{H-L},0,1\right)$$

默认展示：左列旧固定标尺与曝光2（复现先前的观看条件），中列全实际范围展开，右列独立可调的窗口／幂次（默认等于中列）。可选0.5%–99.5%窗口用于检查极值是否压住主体，不作为科学阈值或默认丢弃；显示黑白端点、源跨度和放大倍数。

恒定或全零通道不能拉出纹理。恒定非零保持旧参考灰度并明确标记，全零保持零。窗口收窄或全展开只改灰度，不做空间门槛、随机抽点、平滑、补面、改变尺寸或谱分解。所有候选小块位置仍绘制；黑色是窗口下端的显示值，不等于原始参数为空或没有信息。若真实源数据为全零，则单独提示。

输入灰度可见端点是当场选取的显示规则，波动越小放大越大；必须显示其幅度，不能因此称源数据结构越强。每张量独立标尺不支持跨张量绝对亮度比较。未经厂家标定，这些只是数值／三维观察，不是玻璃成品模拟。

## 本轮结果

副本目录：`prototype/contrast_survey/20261122-033209-256746/`。65功能组、124张量逐字复制，369个可用非负幅度通道分别展开；本批实际通道全部非恒定，恒定与全零策略另外以合成例检查。不复制GGUF大权重，仅复制已有统计，不重新解码／池化／SVD。

原manifest、124原张量JSON及6个原观察文件共131个原件的SHA256前后完全一致；副本的 `source_data/` 和 `original_files/` 与这些原件逐字相同。`data/` 保留全部原值、谱设置、折叠计数，再增加 `windows` 和 `expanded`，检查未改写原字段。

浏览器证据在本副本的 `verification-20261122-033717/verification.json`，截图总览为该目录的 `gallery.html`。核验覆盖66项×4通道＝264个观察组合，Python验证369个实际通道均展开到0–1、JS逐格映射一致、全部候选格实例保留、无效窗被拒绝、恒定例不造纹理、旧曝光不影响展开列、保存结果包含全部灰度及实际三维像素贡献。390px视口无横向溢出，未检测到JS异常。数值和渲染检查完成后只给页面增加截图总览入口，没有改动算法或数据。

65个功能组各保存完整幅度和谱／直接特征两张图，共130张，截图名含功能组ID与通道；不是只截几个较好看的例子。截图左列复现旧标尺曝光2，中列按全实际区间展开，右列默认和中列相同，可以手调。不使用空间门槛，黑色小块也保留为几何；显示黑不解释成原值缺失。

实际查看了MLP完整幅度及谱特征、GDN输入和Embedding截图。此前“没有起色”的视觉判断至少有重要的显示成分：真实差异存在，但固定标尺未展开，曝光又造成饱和。这不否认池化确实减小了幅度波动；本轮只表明不能依据未展开的截图判定权重内容不可看。
