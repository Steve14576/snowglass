# editor_ux 版本目录

同一时刻只有**一个**在用的批次目录，名字是生成时间戳，不是版本号。

- 当前：`20261122-055413-124110/`
- 入口：`20261122-055413-124110/index.html`
- 服务：`http://127.0.0.1:8128/`（项目根 `index.html` 会跳到这里）
- 检查：`20261122-055413-124110/verification/run-<时间戳>/checks.json`

换新批次时，把项目根 `index.html` 的跳转路径改到新目录，并在根 `README.md` 更新同一条信息。旧批次目录保持不动，作为历史快照，不删除、不覆盖。

本目录不放历史页面；旧编辑器与早期试验页在 `prototype/_archive/`。
